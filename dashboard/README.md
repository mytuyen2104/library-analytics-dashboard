# Library Analytics Dashboard

Thư mục này chứa các tệp Dashboard phục vụ trực quan hóa dữ liệu thư viện.

## Chức năng
- Hiển thị tổng số lượt mượn sách.
- Hiển thị tổng số lượt truy cập tài liệu điện tử.
- Thống kê hoạt động mượn sách theo thời gian.
- Hiển thị biểu đồ cột, biểu đồ đường và biểu đồ tròn.
- Phân tích nhu cầu sử dụng tài liệu.
- Hiển thị danh sách gợi ý bổ sung sách.
- Lọc dữ liệu theo thời gian, thể loại và tên tài liệu.

## Công nghệ dự kiến
- Microsoft Power BI
- Power Query

## Yêu cầu
Dashboard có ít nhất 5 biểu đồ và hiển thị số liệu chính xác.
