# Project Screenshots

Thư mục này lưu trữ hình ảnh minh chứng quá trình thực hiện dự án.

## Nội dung
- Ảnh thiết kế cơ sở dữ liệu.
- Ảnh tạo bảng và chạy truy vấn SQL.
- Ảnh giao diện Dashboard.
- Ảnh biểu đồ thống kê.
- Ảnh chức năng lọc dữ liệu.
- Ảnh danh sách đề xuất bổ sung tài liệu.
- Ảnh kiểm thử hệ thống.
- Ảnh triển khai và truy cập Dashboard trực tuyến.

## Quy định
- Đặt tên hình ảnh rõ ràng, dễ nhận biết.
- Không lưu ảnh chứa mật khẩu hoặc thông tin nhạy cảm.
- Sử dụng hình ảnh làm minh chứng cho báo cáo và Daily Report.
