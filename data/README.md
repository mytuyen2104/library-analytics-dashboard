# Sample Library Data

Thư mục này chứa dữ liệu mẫu phục vụ xây dựng và kiểm thử hệ thống.

## Các nhóm dữ liệu
1. Dữ liệu sách:
   - Mã sách
   - Tên sách
   - Tác giả
   - Thể loại
   - Số lượng bản sách

2. Dữ liệu độc giả:
   - Mã độc giả
   - Loại độc giả

3. Dữ liệu mượn trả:
   - Mã lượt mượn
   - Mã sách
   - Mã độc giả
   - Ngày mượn
   - Ngày trả

4. Dữ liệu truy cập điện tử:
   - Mã truy cập
   - Tên cơ sở dữ liệu
   - Ngày truy cập
   - Số lượt truy cập

## Lưu ý
Dữ liệu được tạo giả lập để phục vụ học tập và nghiên cứu.
Không sử dụng thông tin cá nhân thật của sinh viên.
