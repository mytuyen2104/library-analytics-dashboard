# SQL Queries

Thư mục này chứa các câu truy vấn SQL phục vụ thống kê và phân tích dữ liệu thư viện.

## Nội dung
- Thống kê tổng số lượt mượn sách.
- Thống kê lượt mượn theo ngày, tháng và năm.
- Thống kê 10 tài liệu được mượn nhiều nhất.
- Thống kê lượt truy cập cơ sở dữ liệu điện tử.
- Phân tích nhu cầu sử dụng tài liệu theo thể loại.
- Xây dựng truy vấn đề xuất bổ sung tài liệu.
